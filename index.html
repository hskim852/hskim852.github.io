오르비스 캘린더

구글 캘린더와 양방향으로 동기화되는 개인용 캘린더 앱 · Windows / Android

소개

오르비스 캘린더는 개인이 사용하기 위해 만든 캘린더 애플리케이션입니다. 사용자의 구글 캘린더 일정을 한 달 화면에 빽빽하지만 읽기 좋게 보여주고, 일정 추가·수정·삭제가 휴대폰, PC, 구글 캘린더에 모두 즉시 반영됩니다.

주요 기능

  • 월간 보기 중심의 빠르고 깔끔한 일정 확인
  • 구글 캘린더 양방향 동기화 (여러 캘린더 표시 선택 가능)
  • 일정 알림(리마인더)·반복 일정 설정
  • 오프라인에서도 작성 가능, 온라인 연결 시 자동 반영
  • Windows 트레이 상주, Android 폴더블 넓은 화면 지원

데이터 처리

이 앱은 개발자 서버 없이 동작합니다. 캘린더 데이터는 사용자의 기기와 사용자 본인의 구글 계정 사이에서만 오가며, 자세한 내용은 개인정보처리방침을 참고하세요.
