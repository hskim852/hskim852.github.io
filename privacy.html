개인정보처리방침

시행일: 2026년 10월 29일 · 오르비스 캘린더 (Windows / Android)

1. 개요

오르비스 캘린더(이하 "앱")는 개인용으로 개발된 캘린더 애플리케이션입니다. 앱은 개발자가 운영하는 서버 없이 동작하며, 개발자는 사용자의 어떠한 개인정보도 수집·저장·전송·판매하지 않습니다.

2. 구글 사용자 데이터의 이용

앱은 사용자가 직접 구글 계정으로 로그인한 뒤, 구글 캘린더 API를 통해 사용자 본인의 일정 데이터에 접근합니다. 이 데이터는 다음 목적에만 사용됩니다.

  • 사용자의 캘린더 일정을 기기 화면에 표시
  • 사용자가 요청한 일정의 추가·수정·삭제를 구글 캘린더에 반영

일정 데이터는 사용자의 기기와 구글 서버 사이에서만 직접 전송되며, 제3자나 개발자에게 전송·공유되지 않습니다. 앱이 기기에 저장하는 것은 로그인 토큰과 화면 표시용 캐시뿐이며, 모두 사용자의 기기 안에만 보관됩니다.

앱의 구글 사용자 데이터 이용은 Google API 서비스 사용자 데이터 정책 (제한된 사용 요건 포함)을 준수합니다.

3. 수집하지 않는 것

  • 이용 통계, 광고 식별자, 위치 정보 등 어떠한 데이터도 수집하지 않습니다.
  • 분석 도구, 광고 SDK, 추적 기술을 사용하지 않습니다.

4. 접근 권한 철회 및 데이터 삭제

  • 앱을 삭제하면 기기에 저장된 토큰과 캐시가 함께 삭제됩니다.
  • 구글 계정에 부여한 접근 권한은 구글 계정 보안 설정에서 언제든지 철회할 수 있습니다.
